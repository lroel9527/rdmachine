装好了

装了服务端的话，还要在“系统设置 → 隐私与安全性”里给 RDMachine Server 打开两项权限（第一次连接时 macOS 也会提示）：

  • 屏幕录制：没有它连上也看不到画面；
  • 辅助功能：没有它只能看，不能操作。

如果“系统设置 → 通用 → 登录项与扩展 → 允许在后台”里列出了 RDMachine Server，保持打开。

以后管理服务（状态、停止、卸载）用应用里带的命令，例如：
"/Applications/RDMachine Server.app/Contents/Resources/rdmachine-service" status

装了客户端的话，在“应用程序”里打开 RDMachine，输入被控 Mac 的地址即可。
