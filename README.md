# RDMachine

**在 Tailscale 局域网里用的 Mac 远程桌面：功能对标 macOS 屏幕共享，流量少得多。**

画面采集、编码和传输由 [rdaccel](https://github.com/lroel9527/rdaccel) 负责；RDMachine 负责其上的服务端、登录、会话和客户端。当前版本 **7.0.0**：功能已经完成，之后只修问题，不再加新功能。

## 优势

**省流量，文字不糊**

- 画面按区域分类传：没变的不发，平移（滚动、拖窗）只发拷贝指令，出现过的内容从客户端缓存贴回，文字和界面走无损调色板，只有真正在动的区域才用硬件 HEVC 编码。静止桌面几十 kbps，打字约 50 kbps。
- **省流量模式**（显示 → 省流量）：静止和正在输入的文字流量降到平时的 1/3 到 1/7，文字照样精确、立刻到，不出现色块和模糊；省下的是壁纸、图标、影片这些不是文字的地方。
- 声音安静时一个包都不发，客户端静音时也不发。

**用起来像在本机**

- **用这台 Mac 的输入法打字**：组字和候选窗在客户端本机画，贴着远程应用的光标，不用等网络来回；用的是你自己的词库和习惯，被控端不用装同样的输入法。
- **桌面跟着窗口走**：被控端按客户端窗口的像素和缩放建一块虚拟显示器，一个像素对一个像素（HiDPI）；调整窗口、进出全屏、换屏幕后桌面跟着重建。没有接显示器的 Mac 也能用。
- **扩展桌面**：客户端全屏时，这台 Mac 的每块屏幕对应被控端的一块显示器，按这里的排列放好。
- **键盘全给对方**：⌘Q、⌃⌘F 等快捷键都发过去，只有 ⌃⌥⌘F 留在本机进出全屏。

**省事**

- **开机就能连**：服务端作为系统服务运行，连得上登录窗口和锁屏，并替你填好密码；有人登录、退出时会话在同一条连接上换到新桌面。
- **记住密码、自动重连**：第一次登录后密码存进本机钥匙串；打开客户端直接连上次那台，断线后在同一个窗口自动重连。
- **复制粘贴文件**：文本、富文本、图片、文件和文件夹两边互相复制粘贴；文件在访达里 ⌘V，对方真正粘贴时才传，访达显示进度，断线后接着传，内容压缩着走。
- **声音**：被控端的声音在客户端播放，被控端自己不出声。
- **多台电脑**：客户端主窗口列出连过的电脑和它们的在线状态，可以同时连多台，每台一个窗口；可以起别名、分组。
- **只观看**：⌃⌥⌘O，只看画面，键盘鼠标不发过去。
- **统计浮窗**：帧率、延迟、丢包、流量累计、“操作到画面”的延迟。

## 限制

RDMachine 为一个固定的场景而做：作者自己的几台 Mac，用 Tailscale 连在一起。场景外的需求不做，选之前请看清楚：

- **只支持 Mac ↔ Mac**：两端都要 macOS 14.2 或更新（Apple 芯片和 Intel）。没有 Windows、Linux、iOS、浏览器客户端。
- **只在局域网或 Tailscale 里用**：没有打洞、中继、账号和设备 ID。客户端要能直接连到被控端的 TCP 和 UDP 4100；画面只走 UDP，UDP 不通就连不上。
- **不追求画质**：没有 HDR、4:4:4、无损视频。要高画质就用 macOS 自带的屏幕共享。省流量模式下，不是文字的内容（照片、影片、图标）会明显变差。
- **一台被控端同一时间只服务一个客户端**：第二个客户端登录会接管会话，前一个断开。
- **不做的**：拖放文件（用复制粘贴）、被控端屏幕变黑（隐私屏）、远程重启、终端和端口转发（用 ssh）、客户端麦克风传到被控端。
- **开着 FileVault 时**，被控端重启后停在开机解锁界面，这时连不上。
- **安全按自用设计**：登录过就可信。客户端把被控端账号的密码存在本机钥匙串里，服务端用它解锁锁屏；没有双因素、审批弹窗、会话过期。传输有 TLS 1.3 加密，第一次连接核对服务端指纹。不适合给别人用或暴露在公网上。
- **没有 Apple 开发者签名**：pkg 没有签名，第一次打开要手动放行；里面的应用用固定的自签证书签名。
- **依赖 macOS 未公开的行为**：虚拟显示器用 `CGVirtualDisplay`，登录窗口的输入靠一个未公开的程序段。macOS 升级可能让这些失效（虚拟显示器建不出来时退回共享真实显示器）。
- **客户端输入法要手动启用一次**：被控端的系统设置里要加上 RDMachine Input（程序加不了）；用法语等非 ASCII 布局时，切到 ABC 打的键在被控端按 ABC 解释。
- **复制的文件**会丢掉组和其他人的权限位（File Provider 的限制）。
- **界面只有中文**。
- **扩展桌面**作者手上没有两块屏的客户端，没有实测过。

## 安装

从 [Releases](https://github.com/lroel9527/rdmachine/releases) 下载 `RDMachine-版本号.pkg`，双击安装：

- 被控的 Mac 勾 **RDMachine Server**：装完就作为服务运行；
- 用来连接的 Mac 勾 **RDMachine**（客户端）；两个都勾也行。

pkg 没有签名，第一次打开会被拦下：macOS 14 在 pkg 上右键“打开”；macOS 15 起去“系统设置 → 隐私与安全性”底部点“仍要打开”。也可以在终端里装：

```bash
sudo installer -pkg RDMachine-版本号.pkg -target /
```

**被控的 Mac 第一次运行时**，在“系统设置 → 隐私与安全性”里给 RDMachine Server 打开：

- **屏幕录制**：画面；
- **辅助功能**：键盘鼠标控制（没有的话只能看不能控）；
- **系统声音录制**：第一次传声音时会问。

另外两项按需打开：

- **复制粘贴文件**：两台 Mac 都在“系统设置 → 通用 → 登录项与扩展”里打开 RDMachine（服务端菜单和粘贴时的提示会带你去）。
- **用这台 Mac 的输入法**：被控端“系统设置 → 键盘 → 输入法 → 编辑… → ＋ → 英语 → RDMachine Input”。服务端菜单里显示“客户端输入法：已启用”就好了。

macOS 防火墙开着时，允许 RDMachine Server 接受传入连接。升级直接装新的 pkg，权限不用重新授予。新旧版本可以互连，新功能要两边都升级才有。

## 使用

### 客户端

主窗口是连过的电脑列表，每台显示已连接（时长、延迟、分辨率）、正在重连、在线或离线。

- **新建连接**：填被控端的地址，用被控 Mac 上账号的密码登录。第一次连接核对服务端指纹（和服务端菜单里的一致后再信任）。
- **之后**：双击列表里的电脑直接连。右键可以编辑地址、别名、分组，忘记密码，从列表删除。
- **断线**：画面变暗，卡片说明发生了什么，倒计时自动重连（最多 1 分钟）。
- **多台**：已经连着时点程序坞图标回到列表，选另一台开新窗口。

菜单：

| 菜单 | 项目 |
| --- | --- |
| 显示 | 进入/退出全屏（⌃⌥⌘F）、全屏时使用所有显示器、只观看（⌃⌥⌘O）、省流量（文字清晰）、省流量时用标准分辨率（1 倍）、播放远程电脑的声音、统计信息 |
| 输入法 | 用这台 Mac 的输入法（默认）／同步键盘语言（被控端跟着切，组字在被控端）／按键原样发 |

省流量模式默认改用 1 倍的桌面（像素只有四分之一，字粗糙一些），想保留 Retina 就取消“省流量时用标准分辨率”。

### 服务端

菜单栏里的显示器图标：状态（谁从哪个地址连着、连了多久）、断开当前连接、本机指纹、权限状态、客户端输入法状态，以及“设置…”（端口、只看不控、剪贴板方向、帧率和码率上限、声音）。

服务端由三部分组成，都由 launchd 启动、崩溃后自动重启：守护进程（root，监听端口、负责登录）、登录窗口 agent、你会话里的菜单栏应用。用 `rdmachine-service`（在 `/Applications/RDMachine Server.app/Contents/Resources/`）管理：

| 命令 | 作用 |
| --- | --- |
| `rdmachine-service status` | 装了没有、谁在运行、监听什么端口 |
| `sudo rdmachine-service start` / `stop` / `restart` | 启动、停止、重启 |
| `sudo rdmachine-service startmode manual` / `automatic` | 不自动启动 / 自动启动 |
| `sudo rdmachine-service install` / `uninstall` | 装成服务 / 卸载（之后菜单栏应用照旧独立运行） |

日志在 `~/Library/Logs/rdmachine-server.log`。

### 端口

| 端口 | 用途 |
| --- | --- |
| TCP 4100 | 控制连接（登录、会话、剪贴板等） |
| UDP 4100 | 画面、光标、输入、声音 |
| UDP 4102 起 | 扩展桌面的其他显示器 |

被控端有多个网络出口（Wi-Fi、网线、Tailscale）时，画面从客户端连上的那个地址发出。

### 命令行

- 在终端里跑服务端、看日志：`./dist/rdmachine-server.sh`（`--port`、`--view-only`、`--fps` 只对这一次生效，`--headless` 不显示菜单栏图标）。
- 不开窗口测试连接：`./dist/rdmachine-connect 服务端地址 --user=账号`，密码从终端输入。

## 从源码构建

```bash
git clone --recursive https://github.com/lroel9527/rdmachine && cd rdmachine
# macOS 14.2+：Xcode 命令行工具 + CMake
cmake -S . -B build -DCMAKE_BUILD_TYPE=RelWithDebInfo -DCMAKE_OSX_ARCHITECTURES="arm64;x86_64"
cmake --build build -j
ctest --test-dir build
```

只能在 macOS 上构建。

### 打包

macOS 按“证书 + 应用标识”记住屏幕录制和辅助功能权限，所以用一张固定的自签证书签名，重新编译后不用重新授权。

```bash
packaging/macos/create-signing-identity.sh   # 每台用来编译的 Mac 做一次，在登录钥匙串里建 “rdmachine Local Signing”
packaging/macos/package.sh --build --pkg      # 编译通用二进制并打包，产物在 dist/
```

这张证书要留着：删掉重建的话，权限都要重新授予。`dist/RDMachine-版本号.pkg` 是发布用的安装程序，旁边还有两个应用、`rdmachine-server.sh` 和 `rdmachine-connect`。
